# SnipTory v008

- History previews now fit the entire image inside an explicitly sized preview area, preserving proportions without cropping. A small inset and dark background frame wide, tall, and square captures consistently.
- History cards use equal widths regardless of the source image dimensions. GIF hover playback uses the same fitted preview area.

Validated with a compile check and release build. Visual testing is left to the user.

Update through **Options → Check for updates**. New installations can use **SnipTory-v008-Setup.exe**. Binaries are currently unsigned.
