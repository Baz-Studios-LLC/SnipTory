# SnipTory v014

First macOS test build, available for Apple Silicon and Intel Macs running macOS 13 or later.

- The same navy/charcoal History and Options design, persistent local captures, fitted thumbnails, hover actions, deletion/clearing, and GIF hover previews for existing GIF entries.
- Native macOS region screenshot selection and primary-display full screenshots. Captures are saved as PNG, copied as image data, and appear in History without reopening it.
- A template menu bar icon: left-click opens History; right-click offers History, capture actions, Options, and Quit. Closing History keeps the utility in the menu bar.
- Configurable screenshot, History, and full-screenshot shortcuts, retaining Option+Shift+S/V/F as defaults. The parser accepts Option and Command aliases as well as the existing Windows labels.
- Copy-only or paste-back behavior. Automatic paste requires macOS Accessibility permission and waits for the destination app and released modifiers. Without permission, the image remains available for manual ⌘V.
- Launch-at-sign-in, restart, and installer-managed updates using an architecture-specific Mac feed. Updates download and apply in one action after checking, with queued saves finishing before restart.

**Testing notes:** This Mac build uses ad-hoc signing and is not Apple-notarized. macOS may require explicitly allowing this downloaded app in Privacy & Security. Place the app in a writable Applications folder before granting Screen Recording / Accessibility access. Permissions, destination-specific paste behavior, and actual update application need user testing.

**Mac scope:** GIF recording and the custom blue/red region selector are not ported in this first build. The GIF recording shortcut/action is hidden on macOS. Screenshot selection uses the native macOS selector; full screenshot captures the primary display. Existing GIF entries still preview and copy as files. Linux remains shared-core preparation only.

Windows retains its existing features. Public versions remain integer labels; packaging metadata uses tool-required numeric formats.

Source-level and automated regression checks run in Windows CI, and the actual Mac executable is compiled and packaged on Apple Silicon and Intel CI runners. Interactive testing is left to the user.
