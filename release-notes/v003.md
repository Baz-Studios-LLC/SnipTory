# SnipTory v003

**Superseded by v004:** the drag overlay could still intercept interface clicks. Use v004 or later.

- Give the title-bar drag region an explicit left origin so Slint cannot center it over the controls.
- Use dedicated header button components with explicit hit areas and stacking for Options and X.
- Keep update controls in Options.

**Verified in the running Windows app:** clicking the gear opens Options; clicking X hides the window; the process remains running in the tray.

Existing installed copies can check for v003 through Options or the tray menu. New installations can use **SnipTory-v003-Setup.exe**. Current binaries are unsigned.
