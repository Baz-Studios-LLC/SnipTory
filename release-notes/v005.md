# SnipTory v005

- Left-clicking the tray icon starts region selection directly. Right-click retains the menu for History, Options, updates, and Exit.
- Add thin, one-physical-pixel blue crosshair guides from the reticle to all four desktop edges. The guides follow the pointer before and during selection and are excluded from saved images.
- Initialize the reticle at the current pointer position when selection opens.
- Show "Preferences saved" briefly, then return the footer to "Ready". A newer capture, paste, or error message is preserved.
- Draw the selection overlay into a reusable off-screen buffer, then display the completed frame once to prevent the selected interior flickering during a drag.
- Add **Alt+Shift+F** and a tray-menu action for an immediate full-desktop screenshot, copied to the clipboard and saved in History.
- Keep Restart and Update buttons equal in width regardless of their labels.

Windows release compilation and automated regression checks are run before publishing. Interactive testing of these changes is left to the user.

Installed copies can update through Options. New installations can use **SnipTory-v005-Setup.exe**. Current binaries are unsigned.
