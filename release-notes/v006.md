# SnipTory v006

- **Alt+Shift+G** opens the same region selector with a white reticle and **red** guide lines and selection border. Release the mouse to begin GIF recording immediately.
- A compact recording bar sits at the bottom center of the selected monitor, with elapsed time, **Stop**, and cancel. Controls are excluded from capture using Windows display affinity.
- Record at a target 12 FPS, original region resolution, with the cursor and no audio. A single-frame queue and streaming GIF encoding keep memory bounded; slow encoding drops intermediate samples while preserving elapsed timing. There is no recording duration limit.
- Stop saves the animated GIF to History, generates a preview and duration badge, and copies the original GIF file to the clipboard. GIF pasting uses a file representation, preserving animation when the destination accepts it; the app does not silently flatten GIFs into still images.
- Stop the active recording before restarting or updating. Exit finishes saving an active recording; cancel discards it.
- Tighten tray-menu height and header alignment. Add Record GIF and remove Check for updates from the tray menu. Update controls remain in Options.

Automated checks cover GIF frame contents/timing and persistent GIF metadata/thumbnails, plus existing screenshot and focus regressions. Interactive recording, capture exclusion, and destination-specific GIF attachment behavior are left for user testing. GIF uses a 256-color palette; protected/HDR content retains the existing GDI capture limitations. Individual raw frames are limited to 64 MiB.

Update through **Options → Check for updates**. New installations can use **SnipTory-v006-Setup.exe**. Binaries are currently unsigned.
