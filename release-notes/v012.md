# SnipTory v012

- Fix stretched and squeezed thumbnails at their source. Thumbnail generation now preserves the original aspect ratio within 400 × 300 instead of resizing every capture to exactly 400 × 300. The fix covers screenshots, GIF still previews, and GIF hover playback.
- Rebuild existing distorted previews from the original captures as History loads, including older entries when loaded. Original screenshots and GIFs are preserved.
- Left-clicking the tray icon now opens History. Capture shortcuts and the right-click capture actions remain available.

Automated checks cover wide, tall, square, small, and extremely narrow previews, plus repairing old PNG/GIF thumbnails while preserving original files. Interactive testing is left to the user.

Update through **Options → Check for updates**. New installations can use **SnipTory-v012-Setup.exe**. Binaries are currently unsigned.
