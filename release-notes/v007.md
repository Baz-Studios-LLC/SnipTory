# SnipTory v007

- Hover over GIFs in History to play them. Moving away restores the still preview. Playback runs on a background worker, decodes frames as needed, and retains at most one queued preview update.
- GIF region selection now shows the live desktop through a translucent overlay. Motion stays visible while selecting, with the existing white reticle and red guides. Screenshot selection retains its frozen preview.
- Delete individual captures using the trash button on each card, or press Delete on the selected capture. Clear history is available in History and Options. Both actions ask for confirmation and delete saved originals and thumbnails.
- Clear history includes older captures beyond the visible page. Settings, unrelated files, and recordings still being encoded are preserved.

Release build and automated regression checks cover capture persistence, PNG/GIF deletion and clearing, deletion path boundaries, live-overlay alpha, GIF encoding/timing, focus handling, title-bar drag boundaries, and integer release labels. Interactive GIF previews, live selection, and deletion controls are left for user testing.

Update through **Options → Check for updates**. New installations can use **SnipTory-v007-Setup.exe**. Binaries are currently unsigned.
