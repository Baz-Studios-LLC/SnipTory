# SnipTory v013

- Add a view button beside the trash button on hovered History cards. It opens the original screenshot or GIF in your default Windows image viewer. Clicking the card still copies/pastes it.
- Make the four global shortcuts configurable in Options. Type a combination and choose Apply shortcuts; changes take effect immediately and persist across restarts and updates. The tray menu shows the saved bindings.
- Keep Alt+Shift+S (screenshot), Alt+Shift+V (History), Alt+Shift+F (full screenshot), and Alt+Shift+G (GIF) as the defaults. Restore defaults fills these combinations for applying again.
- Validate shortcut syntax and duplicate assignments. If Windows refuses a combination, restore the previous bindings and report the conflict. If preferences cannot be saved, revert the applied bindings too.

Automated checks cover shortcut parsing, normalization, duplicate rejection, existing-settings compatibility, persistence, thumbnail proportions and repair, and existing capture regressions. Live Windows hotkey conflicts and external viewer behavior are left for user testing.

Update through **Options → Check for updates**. New installations can use **SnipTory-v013-Setup.exe**. Binaries are currently unsigned.
