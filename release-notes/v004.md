# SnipTory v004

- Remove the Slint drag overlay and its synthetic title-bar mouse message entirely.
- Let Windows move the window only when a mouse press lands in the 73-pixel title bar, excluding the gear and X controls.
- Keep gallery content, Options, and the footer outside the drag region at each monitor's DPI.
- Follow the most recently focused external application while History is open, so focusing a destination after opening History selects the correct paste target.
- Wait for both foreground restoration and modifier release before sending Ctrl+V. Freeze the chosen destination for each paste instead of allowing later focus events to redirect it.
- Keep History open after copying or pasting so several captures can be attached in succession.
- Remove footer instructions and update guidance; keep only capture status and the release label.

Regression checks cover the title bar, header buttons, middle, and bottom at 100%, 150%, and 200% scaling. A middle-of-window drag was checked without moving the window. The user confirmed that the interface now works; further interactive testing is left to the user.

The updated focus path is covered by the paste-readiness regression check. Pasting into Claude Code is left for user validation.

Existing installed copies can check for v004 through Options or the tray menu. New installations can use **SnipTory-v004-Setup.exe**. Current binaries are unsigned.
