# SnipTory v015

- Use the native macOS red/yellow/green traffic-light controls at the top left of History and Options. Red hides the window while SnipTory remains in the menu bar; yellow minimizes; green uses native macOS window behavior.
- Match the native title bar to the charcoal app background, remove the duplicate custom X on Mac, and tighten header spacing. Windows retains its existing window controls and layout.
- Reopening History from the menu bar or shortcut restores it after minimizing.

Windows and Mac builds are checked in CI. Interactive traffic-light behavior is left to the user. Mac GIF recording remains pending; this is still an ad-hoc-signed, non-notarized Mac test build.

Update through **Options → Check for updates**, or download the Mac ZIP for your architecture. Mac screenshots require Screen Recording permission; automatic paste requires Accessibility permission.
