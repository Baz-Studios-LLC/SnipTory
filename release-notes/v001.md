# SnipTory v001

Capture. Recall. Paste. The first Windows 11 release from Baz Studios.

- Region screenshots with **Alt+Shift+S**, PNG storage, and actual image clipboard data.
- Persistent screenshot history with **Alt+Shift+V**, thumbnail previews, keyboard navigation, and paste-back.
- Always-on-top History with Options in the same window.
- A matching charcoal and navy tray menu, white tray glyph, and blue-and-white taskbar icon.
- Saved options for launch at sign-in, automatic update checks, and copy-only selection.
- Restart and check-for-updates controls. Installer-managed updates download inside the app and apply silently on restart.
- MIT-licensed SnipTory source. Third-party dependencies retain their own licenses.

Install **SnipTory-v001-Setup.exe** once. Future releases are delivered through the app. Capture history is stored separately from the application installation and retained across updates.

This is an initial release. GIF recording is planned. Full capture/paste behavior, mixed-DPI hardware, and the first version-to-version update still need hands-on validation. Windows may restrict capture of protected content and paste into elevated applications. Binaries are currently unsigned.
