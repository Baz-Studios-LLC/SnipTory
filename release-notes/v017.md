# SnipTory v017

First Linux x86-64 build targeting Bazzite GNOME on Wayland. Download **SnipTory-v017-linux-x64.AppImage**. See [Linux setup](https://github.com/Baz-Studios-LLC/SnipTory/blob/main/docs/LINUX.md) for executable permission and FUSE-free launch instructions.

- Shared polished History and Options UI, image previews, original-size viewing, deletion, clear History and custom save location.
- Screenshots through GNOME's desktop portal, with native permission and region selection.
- Portal-approved global shortcuts requesting the existing Alt+Shift+S/V/F defaults; reopen History through the GNOME launcher or shortcut.
- Wayland image clipboard copying. Paste manually into the destination app.
- AppImage update checks and download/apply/restart controls; keep the file in a user-writable folder.
- Sign-in launch, background History, and a Quit action without requiring a tray extension.

Linux limitations: GIF recording and automatic paste are not available yet. GNOME controls shortcut approval, focus, and window stacking. Native Linux CI builds/tests and a packaged startup smoke check precede publication; Bazzite GNOME desktop behavior remains for user testing. Windows and Mac builds are included. This release does not claim to fix the reported Mac update installation problem.
