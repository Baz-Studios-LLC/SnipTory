# SnipTory v011

- Simplify the updater to **Check for updates → Update**. Clicking Update downloads the release, finishes queued saves, applies it, and restarts automatically. There is no separate Download or Restart & update step.
- Show download progress while updating and retain retry controls if downloading or applying fails. If a GIF is recording, stop it and click Update again; the downloaded package is reused.
- Automatic checks still only offer an update. Downloads and restart begin only after clicking Update.

Validated with automated regression checks and a release build. Interactive update testing is left to the user. The simplified flow takes effect after installing v011.

Update through **Options → Check for updates**. New installations can use **SnipTory-v011-Setup.exe**. Binaries are currently unsigned.
