# SnipTory v016

- Choose where new captures are saved from Options → Save location → Change… using the native Windows or Mac folder picker.
- Open the current folder or restore the default location from the same panel.
- Screenshots and GIFs use separate subfolders. Existing captures remain in their original locations and stay accessible in History, including after restarting.
- Keep the history database and previews in the app data folder. Unavailable or unwritable destinations report an error instead of silently saving elsewhere.

Validation: Windows release build and automated storage tests; native Apple Silicon and Intel builds and tests through GitHub Actions. Hands-on UI testing is left to the user. This release does not claim to resolve the reported Mac updater installation issue.
