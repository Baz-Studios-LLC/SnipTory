# SnipTory v010

- Refresh History immediately after a screenshot is saved. New region snips and full screenshots appear while History remains open, without closing and reopening the window. The refresh follows the completed file and database save, using the same background gallery-loading path as GIF captures.

Validated with a release build. Interactive testing is left to the user.

Update through **Options → Check for updates**. New installations can use **SnipTory-v010-Setup.exe**. Binaries are currently unsigned.
